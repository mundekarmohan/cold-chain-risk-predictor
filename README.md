
# Cold Chain Risk Predictor

A machine learning web application that predicts fruit storage condition classes.

## Dataset
Dataset.csv with fruit type, temperature, humidity, light, CO2, and class.

## Technologies
- Python
- Pandas
- Scikit-learn
- HTML, CSS, JavaScript
- Vercel

## Run the training script

```bash
python train_model.py
```

## Output
The model predicts the Good or Bad class based on the input readings.

Note: Predictions are not a certified food-safety assessment.
